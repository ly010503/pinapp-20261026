# 原型图搜索

只解决“找到值得作为底图原型的公开图片”。独立完成文字搜索、浏览结果、人工视觉筛选和候选交付，不调用其他 Skill，也不继续执行图片生成或拼豆流程。

## 硬性约束

- 禁止以图搜图、反向图片搜索或把用户参考图上传给搜索网站。
- 只使用文字关键词、平台站内搜索、公开网页搜索和逐条浏览作品。
- 可以观察搜索结果是否符合用户描述；这属于筛选，不得把候选图再次用于反向搜索。
- 不要求用户发送账号、密码、验证码或 Cookie。需要登录时打开用户自己的浏览器，让用户扫码或手动登录一次，然后复用现有登录状态。
- 遇到验证码、风控或异常登录时停止自动交互并让用户接管；不绕过验证，不调用未公开、逆向或抓包得到的接口。
- 默认只交付候选图和来源。只有用户明确要求保存、下载或选定编号后，才保存相应公开图片。
- 保留平台、作者和原作品链接，不能把转载页面误写成原始来源。

## 默认行为

用户没有另行指定时：

- 同时搜索抖音和小红书；某个平台不可用时继续搜索另一个并说明。
- 返回最多 12 张合格候选，而不是堆积大量相似图片。
- 优先图文作品中的静态图片。视频封面或截帧只有在用户明确接受时才作为候选。
- 每个平台最多浏览约 50 条结果，最多进行 3 轮关键词调整。达到候选数量或上限后停止。
- 不因缺少服装、数量等次要信息而反复追问；使用合理默认值继续搜索。只有人物身份或目标类型无法确定时才问一个简短问题。

## “嘎子姐”固定识别标准

用户说“嘎子姐”时，默认指其提供样例中的同类潮玩娃娃实拍图，而不是真人或普通娃娃：

- 大头小身体，圆形灰白或浅色大眼，小巧下撇嘴。
- 脸部两侧具有醒目的尖状轮廓，整体是可换装潮玩娃娃造型。
- 发色、发型、帽子、眼镜、服装、鞋子和配饰可以变化。
- 优先单个娃娃、完整全身或接近完整全身、正面或轻微侧面、竖版居中。
- 背景简洁、主体清楚；底部有人手托举可以接受。
- 排除真人、动漫插画、AI 生成图、像素图、其他脸模娃娃、多人合照、脸部严重遮挡、大面积字幕和明显低清图。

人物/脸模是否正确永远比衣服是否相似更重要。不要因为服装好看而收录身份明显不符的娃娃。

## 工作流

### 1. 提取需求

从用户原话提取人物、平台、数量、全身/半身、视角、动作、表情、发型、服装、配饰、背景和清晰度要求。将“必须满足”和“偏好”分开，搜索中优先守住人物身份与构图硬条件。

### 2. 扩展文字关键词

围绕目标名称生成少量互补关键词组合，包括：

- 名称本身、常见别名、昵称或话题标签；
- 名称 + 娃娃/潮玩/改娃/穿搭/造型；
- 名称 + 全身/正面/侧面/特写；
- 名称 + 用户指定服装、发型、动作、季节或颜色；
- 平台结果不足时尝试中英文造型词，但不得通过图片寻找相似项。

“嘎子姐”常用起始词可以包括：`嘎子姐`、`嘎子姐娃娃`、`嘎子姐穿搭`、`嘎子姐改娃`、`嘎子姐全身`、`嘎子姐造型`。根据实际结果保留有效词，淘汰带来大量真人或无关娃娃的词。

### 3. 搜索平台

使用当前环境可用的浏览器控制能力直接操作网页，不调用另一个 Skill：

1. 优先连接用户已登录的浏览器窗口或持久浏览器配置。
2. 在平台搜索框输入文字关键词，优先查看图文、图片或相关话题结果。
3. 打开可能合格的作品，检查多图内容；不要仅凭小缩略图判断。
4. 记录平台、作者、标题、原作品链接和候选图片在作品中的序号。
5. 返回列表后继续下一组关键词，直到数量满足或达到停止条件。

若浏览器控制不可用，可以使用普通网页搜索限定平台域名寻找公开作品链接；不得因此切换到以图搜图。

### 4. 筛选和去重

每次筛选前读取 [references/search-ranking.md](references/search-ranking.md)。先执行硬性淘汰，再按身份、构图、清晰度、遮挡、背景和造型价值评分。

同一作品里的连续近似照片通常只保留最完整、最清楚的一张。跨平台转载的同一张图只保留更接近原作者或信息更完整的来源。

### 5. 交付候选

在对话中优先展示可见缩略图或页面截图，并给每张候选固定编号。每项至少包含：

- 编号；
- 平台与作者；
- 原作品链接；
- 推荐度；
- 一句推荐理由；
- 必要时标注裁切、遮挡、水印或清晰度问题。

结果按推荐度排序。候选不足时交付已有合格项并说明原因，不用明显不合格图片凑数。最后提示用户可以直接回复编号，例如“要 2、5、8”。

### 6. 保存选中图片

用户明确选择编号或要求下载后：

1. 重新核对编号、作品链接与目标图片一致。
2. 优先保存作品公开展示的最高可用清晰度版本，不用缩略图冒充原图。
3. 保存到用户指定位置；未指定时保存到 `G:\2_pinapp\workflow-output\reference-images\`，使用不会覆盖旧文件的名称。
4. 同目录记录一个简短来源清单，包含文件名、平台、作者和原作品链接。
5. 报告保存结果；无法合法、稳定下载时保留链接并说明，不尝试绕过平台限制。

## 完成标准

- 搜索过程没有使用以图搜图或上传参考图。
- 候选符合用户描述，嘎子姐任务没有混入真人或其他脸模娃娃。
- 每张候选都有可追溯的原作品链接。
- 数量达到要求，或已经达到搜索上限并如实说明不足。
- 未经用户选择时没有批量下载候选图片。

## 异常处理

- 需要登录：保持页面打开，请用户扫码或手动登录，完成后继续。
- 验证码或风控：停在当前页面交还用户，不连续重试。
- 页面只有视频：继续寻找图文；除非用户允许，否则不交付视频截帧。
- 作品已删除或链接失效：淘汰该候选，不交付无法追溯的图片。
- 两个平台结果都差：扩展文字关键词到公开网页，但仍需保留原始出处并禁止以图搜图。
