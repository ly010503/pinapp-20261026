# 照片转拼豆工作流

把重复的前半段自动化：照片动漫化、确认、保存、打开网站、上传和生成初始图纸。初始拼豆图出现后立即交还页面，不替用户进行细格修改或导出。

## 必读资料

- 每次生成或修改图片前读取 [references/style-profile.md](references/style-profile.md)。
- 每次打开或操作拼豆网站前读取 [references/site-profile.md](references/site-profile.md)。
- 每次生成或修改完成后，用 `scripts/normalize-perler-image.ps1` 核验并规范化最终画布。

## 工作流

### 1. 接收并识别图片角色

1. 将用户本轮上传的照片作为主体和造型依据。
2. 用户上传多张图片时，根据文字说明区分主体图、画风参考图和修改目标图；不清楚且会实质改变结果时，只问一个简短问题。
3. 用户只说“这个也这样生成”时，沿用本 Skill 的默认画风，不要求用户重复说明。
4. 不读取或猜测照片以外的身份信息。

### 2. 生成一张非像素 Q 版素材

1. 使用内置 `image_gen` 路径；不要切换到需要 API Key 的 CLI。
2. 默认只生成一张，不同时生成像素版、拼豆版或多候选版。
3. 将原照片视为需要保留主体特征的编辑目标或高保真参考；画风参考图只控制画风，不覆盖主体身份、姿势和服饰。
4. 使用 `style-profile.md` 的基础提示词、默认 `1024×1536` 竖版分辨率和其中“偏粗黑色描边”的默认基准，并补充原图中实际可见的发型、视线、嘴型、服装、鞋子、配饰和文字等关键特征。
5. 读取生成文件的实际像素尺寸；不要根据提示词、预览尺寸或旧网站图片推断尺寸。
6. 实际尺寸不是 `1024×1536` 时，运行 `scripts/normalize-perler-image.ps1`，在纯白 `1024×1536` 画布上等比例缩放并居中，不拉伸、不裁掉主体；后续展示、修改和上传都使用规范化文件。
7. 生成后检查主体、视线、轮廓、背景和关键配饰。明显违反硬性要求时，先做一次定向修正再展示。
8. 在对话中展示规范化后的结果，并用一句话提示：“满意请回复‘上传’，需要修改直接告诉我具体位置。”

### 3. 按反馈定向修改

1. 用户提出修改时，将上一张生成图作为编辑目标，并继续保留原照片作为主体依据。
2. 每轮只修改用户指出的问题；明确列出必须保持不变的内容，避免人物、姿势、衣服和配饰漂移。
3. “重新做”“不好看”等笼统反馈出现时，优先重新生成同一风格的一张，而不是同时给很多候选。
4. 修改完成后再次核验实际尺寸；不是 `1024×1536` 时重新规范化，再展示并等待确认。

### 4. 设置上传确认门

只有用户对当前成品明确说“上传”“可以上传”“就这张”“满意”“可以”等确认语，才能进入网站步骤。

确认前：

- 不打开网站。
- 不替用户选择一张尚未确认的图片。
- 不将早期草稿当作最终素材。

### 5. 保存最终素材

1. 找到本轮明确确认且已经核验为 `1024×1536` 的规范化图片文件；不得使用尺寸不符的原始生成文件。
2. 将最终图片非破坏性地复制到 `G:\2_pinapp\workflow-output\`。
3. 使用可辨认且不覆盖旧文件的名称，例如 `perler-source-20260731-153000.png`。
4. 保留 PNG、JPG 或 WebP 格式；网站支持的单文件上限为 40 MB。
5. 记住最终绝对路径，后续上传必须使用这一个文件。

### 6. 打开网站并生成初始图纸

1. 按 `site-profile.md` 连接浏览器并打开线上拼豆网站。
2. 将最终文件上传到网站的图片输入框。
3. 验证页面出现缩略图、文件名和图片尺寸；不能仅以点击成功作为上传完成。
4. 用户没有指定设置时，保留网站推荐值：
   - 竖版 `70 × 104`
   - 最多 `24` 色
   - `鲜艳`模式
5. 不自动裁剪、旋转或翻转。用户已明确要求这些操作时才执行。
6. 点击“生成我的拼豆图纸”，等待图纸区域出现且进度结束。
7. 将浏览器停留在结果编辑区并交还用户。

### 7. 人工接管

初始图纸生成后立即停止自动操作。明确告诉用户：

- 页面已经打开并生成初始拼豆图。
- 用户现在可以手工点格、换色、留白并导出。

除非用户之后另行明确要求，否则不要：

- 自动替换颜色或修改格子；
- 自动判断最终成品是否合格；
- 自动保存效果图、制作图或镜像图；
- 关闭、刷新或离开该页面。

## 异常处理

- 图片生成失败：报告失败并重试一次；仍失败则停下说明。
- 线上网站需要登录：保持页面打开，请用户在当前浏览器登录后继续。
- 线上网站网络不可用：按 `site-profile.md` 启动本地备用版本，再继续上传。
- 自动文件上传不可用：保持网站和文件位置准备好，告诉用户只需手动点击一次上传；不要反复切换浏览器。
- 图纸生成失败：保留页面和已上传图片，说明页面提示，不擅自改参数连续重试。

## 完成标准

只有同时满足以下条件才算完成：

1. 用户确认的是当前展示的最终动漫素材。
2. 最终文件已保存到项目输出目录。
3. 网站已显示该文件的上传信息。
4. 初始拼豆图已经生成。
5. 浏览器停留在可供用户手工修改的结果页面。
