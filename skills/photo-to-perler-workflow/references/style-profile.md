# Q 版拼豆素材画风

## 目标

生成适合随后交给拼豆网站降采样和色卡匹配的非像素动漫素材。优先保证人物辨识度、偏粗且连续的黑色轮廓和大色块，而不是追求复杂插画质感。

已验证偏好：默认直接采用醒目的偏粗黑色线稿，不从普通动漫细线或中等粗细开始。用户确认的理想强度，是在已经明显加粗的轮廓上再增加约 10–15% 的线宽；以后首轮生成就以这个最终强度为基准。

默认输出规格：`1024×1536` 像素竖版（2:3）。除非用户明确指定其他尺寸，否则首轮生成和后续修改都保持这一分辨率与画布比例。提示词中的尺寸不是完成证明；必须读取生成文件的实际像素尺寸。尺寸不符时，使用 Skill 自带脚本将完整主体等比例缩放并居中到纯白 `1024×1536` 画布，禁止拉伸或裁掉主体。

## 基础提示词

```text
用途：拼豆图纸生成器的非像素 Q 版动漫素材
输出：1024×1536 像素竖版（2:3）

以用户照片为唯一主体、造型和构图依据。将主体转换成干净可爱的 Q 版动漫插画，但不要生成像素画或拼豆图纸。

保持原图人物的发型、眼睛和视线方向、嘴型、姿态、服装颜色、裤子、鞋子、配饰以及有辨识度的随身物品。原图为全身时保留完整全身；原图为半身或头像时保持原构图类型，不擅自虚构看不见的身体细节。

使用纯白 #FFFFFF 背景。主体与背景完全分离，周围留出适度白边。使用非常粗、醒目、连续且粗细稳定的黑色主外轮廓，默认达到偏粗漫画墨线的强度，缩小到 70×104 格时仍能一眼读清轮廓；主外轮廓约为关键内部线的 1.5～2 倍。内部结构只使用少量、同样清楚但略细的黑线。使用清晰的大面积平涂色块，每个区域最多保留少量块状阴影。相邻区域要有明显明度或色相对比。

减少细碎发丝、衣服褶皱、纹理、渐变、反光、噪点和没有辨识作用的小装饰，但不要删除原图中的关键特征。

不要添加新人物、新配饰、新背景元素、投影、文字说明、水印、边框、网格、像素格、编号或色卡。不要生成像素风、马赛克或拼豆颗粒效果。
```

## 硬性检查

展示前逐项检查：

1. 人物数量和原图一致，没有多肢、缺肢或重复配饰。
2. 发型、脸型、视线方向、嘴型和姿势没有明显改变。
3. 衣服主色、裤子、鞋子和重要配饰得到保留。
4. 帽子、包、眼镜等关键物品没有被头发或其他元素错误遮挡。
5. 原图中清晰可辨且用户重视的文字方向和拼写正确；无法可靠保留时不要编造，并主动说明。
6. 背景为均匀纯白，没有地面、阴影、渐变或装饰。
7. 黑色主外轮廓达到验证过的偏粗强度，明显粗于内部线，缩小到 70×104 格时仍连续清晰，没有被阴影吞没。
8. 画面是平滑非像素插画，没有网格、豆子或伪像素。
9. 已读取最终文件并确认画布实际为 1024×1536 像素竖版；后续修改不得擅自改变分辨率或比例。

## 常见反馈的定向修改

| 用户反馈 | 修改动作 | 必须保持 |
|---|---|---|
| 黑边再粗一点 | 在已偏粗的默认基准上小幅增加约 10～15%，仅调整主体外轮廓和关键内部轮廓 | 人物比例、颜色、姿势、表情 |
| 眼睛方向反了 | 按原照片修正瞳孔和眼镜方向 | 头部朝向、脸型、其他五官 |
| 背景改纯白 | 删除全部背景、地面和投影 | 主体本身完全不变 |
| 不像本人 | 强化发型、脸型、眼镜、嘴型等身份锚点 | Q 版画风和简化程度 |
| 拼豆后太碎 | 合并近似颜色，删除纹理和小阴影，扩大色块 | 外轮廓和身份特征 |
| 拼豆后轮廓糊 | 加粗轮廓，提高相邻区域对比 | 姿势和服装设计 |
| 关键文字被挡住 | 调整头发或遮挡关系，让原有文字完整可见 | 配饰形状、人物姿势 |
| 重新生成 | 重新生成同一规格的一张 | 原图主体和全部硬性要求 |

每轮编辑只处理本轮反馈。提示词中重复写明“除上述修改外，其余内容保持不变”。
