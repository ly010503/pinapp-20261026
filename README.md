# 拼豆图纸生成器

一个在浏览器本地完成图纸计算的拼豆图纸工具。相册图片不上传服务器；原图、设置和当前图纸会自动存入当前浏览器的 IndexedDB，首页可恢复最近一份草稿。清除网站数据会移除草稿，跨浏览器、跨电脑请保存 `.perlerproj` 工程文件。链接图片仅经后端临时转发，导入后同样参与本机草稿保存。

> 项目使用 MARD 标准 221 色的屏幕近似色卡（A、B、C、D、E、F、G、H、M 系列）。显示颜色不等同于实体豆的官方测量值，购买材料请按色号并以实体色卡为准。

## 安装与运行

安装依赖：

```bash
npm install
```

启动开发环境：

```bash
npm run dev
```

构建生产版本：

```bash
npm run build
```

本地预览生产版本：

```bash
npm run preview
```

运行算法测试：

```bash
npm test
```

## 当前功能

- 连续画笔、橡皮擦和四向连通区域填色；快拖经过的格子会自动补齐，一笔只记一次撤销；触屏双指缩放和取消手势会撤回未提交的一笔
- 画笔与橡皮擦在制作图中工作，进入工具时自动放大；快捷键 B 画笔、E 橡皮擦、G 区域填色、V 移动、S 选格换色
- 可勾选已有 MARD 色号、批量录入色号、从当前图纸用色建立个人色板，并在本机保存最多12套命名色板；开启后同时限制生成、画笔和换色，颜色数量上限仍独立生效
- 已有色号随工程与草稿保存；有序模式缺少 H7 时使用可用色板中的深色画轮廓，绝不额外加入缺少的色号
- 首页展示真实原图与算法生成图纸，支持一键试做小猫示例
- 生成后切换到电脑端设置／画布／用豆三栏工作区；手机端通过底部三个面板切换
- 原图、编辑设置、留白蒙版和图纸自动保存为本机草稿，刷新后可继续；保存失败有状态提示与重试入口
- 可见的撤销与重做按钮；Ctrl/Cmd+Z 撤销、Ctrl/Cmd+Shift+Z 或 Ctrl+Y 重做，支持改色和尺寸调整，最多20步；新编辑会清空重做分支
- 工程文件保存与打开，包含原图、设置、图纸及留白蒙版，兼容旧版工程文件
- JPG、PNG、WebP 点击/相册选择和拖拽上传
- 支持粘贴抖音图文或小红书图文分享链接，读取多图后由用户选择一张导入；视频作品会明确提示不支持
- 首页可直接上传已有网格图纸截图并自动识别横纵格数、排除坐标栏、逐格恢复底色；检测到规则色块图例时仅在图例色卡内匹配，没有图例时自动回退到完整色卡
- 图纸生成并改色后可直接按目标宽高居中裁掉网格边缘，不重新识别；奇数差值由左侧、上侧多裁一格，并支持撤销
- 触摸友好的自由、正方形、竖版、横版和图纸比例裁剪
- 左右旋转、水平翻转、恢复原图、重新上传
- 50×50、64×64、70×70、90×90、104×104、70×104和自定义尺寸
- 自动识别图片实际需要的颜色，用户只设置15、24、48、96或221色上限
- 自然、鲜艳与有序颜色效果；有序模式让相近颜色形成连续色块，并用独立人物蒙版生成 H7 外轮廓和轮廓外留白
- Web Worker 本地色卡匹配、限色和孤立点整理
- 效果图与带清晰编号、坐标、网格、5×5粗辅助线、色卡和统计的制作图
- 单指拖动、双指缩放、滚轮缩放、双击放大/恢复和全屏查看
- 真实用豆清单、颜色高亮、展开/收起和复制
- 制作图支持点击单格更换颜色；可换成纯白留白，留白不显示色号且不计入用豆统计
- 桌面端可在制作图格子上点击鼠标右键，立即将该格改为纯白留白
- 独立离屏 Canvas 生成高分辨率效果图 PNG 与高清制作图 PNG
- 导出图使用缩略图中也能辨认的“@小石豆图”大号水印，并大幅标注“原创作品 · 禁止盗用”
- 可开启或关闭铺满式斜向防盗水印，默认文案为“@小红薯 小石豆图”，支持导出前修改
- 镜像制作图左上角显示醒目的“镜像图”标识，文字和色号保持正向
- 一键导出全部分色定位图时，每种颜色同时生成正向版和镜像版，在 ZIP 内分别放入“非镜像”和“镜像”文件夹
- 根据设备内存和图纸大小自动控制导出分辨率，失败时自动降低一级重试

自动识别为纯白背景且不显示 H2 色号的格子，以及手动设置的纯白留白，都不代表实体豆，因此不会计入颜色清单和总豆数；H2 只统计主体中实际显示 H2 色号的白色豆。

## 本次精简

主界面不再展示亮度、对比度、饱和度、锐化、采样方式、色卡品牌、多尺寸预览、专业缩放工具、PDF/SVG/ZIP/CSV 导出、耗时估算和复杂顶部菜单。底层的 Lab 色彩匹配、区域缩放、自动孤立点优化、网格编号与统计仍自动运行。

## 静态部署

运行 `npm run build` 后，将 `dist/` 目录部署到 Vercel、Netlify、Cloudflare Pages、GitHub Pages 或普通静态服务器即可。项目运行时不依赖后端服务。

## 主要目录

- `src/image/`：图片解码、裁剪、旋转和缩放
- `src/color/`：RGB/XYZ/Lab 转换与色卡匹配
- `src/workers/`：耗时图纸计算
- `src/canvas/`：效果图、制作图和触控视口
- `src/export/`：两种离屏 Canvas PNG 导出
- `src/state/`：统一状态和尺寸配置
- `src/data/palettes/`：MARD 221 屏幕近似色卡 JSON
